## Getting started with Jekyll

To add a new post, simply create a file in the `_posts/` directory named
`YYYY-MM-DD-title.md` with a little bit of front matter:

```yaml
---
layout: post
title: My new post
date: 2026-08-18
---
```

That's it! Jekyll will build it automatically.
