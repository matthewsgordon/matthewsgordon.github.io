### Using Minecraft to test memory and prior knowledge
This was the most recent project I was a part of at Edge Hill univeristy, it involved using Minecraft as a research tool for testing memory and spatial navigation. There is a huge psychological context behind the project. I was involved with the software aspect of the project which involved troubleshooting problems with the game, such as commands misstiming or functions not working the way they were intended. The core function of the game was that the player would spawn into one of three arenas. These arenas would all contain sandwells hiding one coloured block for the player to find, the player would begin in one of four starting locations, and would have to find this colour block by mining the sandwells. Then the arena would reset and they would have to remember where the colour block was located, this would repeat through several trials and colours and locations would change throughout. I went on to do my masters of research with this project.

### Maze Project
This projects goal was to create a framework to investigate different NPC pathfinding algorithms in a game setting. The investigation  looks at how these algorithms perform and compare to each other in this environment. The resources being used for this project include Unity3D along with C# as the programming language. The setting for the project is a procedurally generated maze with a static start and end point for the algorithm. The algorithms being used were A*, Dijkstra’s Algorithm and Greedy Best First Search. The main functional aspect of the project was a randomaly generated maze in Unity which generated width and length based on a recursive algorithm. The maze generation was adapted from Unity.learn. There was also node generation, which works by generating 3 different prefabs which represent the start node, the end node and the path nodes. The start and end nodes are generated at random points through the maze and are based on the mazes size, this way the generation is always accurate relative to the maze scale and will not generate at inaccurate locations. Heuristic distance also had to be calculated to keep things accurate. The main goal of this research was to look at the pathfinding algorithms used in games and compare them in a game environment to measure their efficiency and a few other factors.
