### Using Minecraft to test memory and prior knowledge
This was the most recent project I was a part of at Edge Hill univeristy, it involved using Minecraft as a research tool for testing memory and spatial navigation. There is a huge psychological context behind the project. I was involved with the software aspect of the project which involved troubleshooting problems with the game, such as commands misstiming or functions not working the way they were intended. The core function of the game was that the player would spawn into one of three arenas. These arenas would all contain sandwells hiding one coloured block for the player to find, the player would begin in one of four starting locations, and would have to find this colour block by mining the sandwells. Then the arena would reset and they would have to remember where the colour block was located, this would repeat through several trials and colours and locations would change throughout. I went on to do my masters of research with this project.
